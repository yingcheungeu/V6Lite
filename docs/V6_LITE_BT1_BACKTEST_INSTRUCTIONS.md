## 2 回测规则（必须与 V6-Lite 的实际行为一致）

| 项 | 规则 |
|---|---|
| 代码复用 | 直接 import `v6lite.strategy`（`generate_signals`、`effective_min_score`）、`v6lite.exits`（`compute_levels`、`decide_exit`、`buy_limit`、`sell_limit`、`breakeven_stop`）、`v6lite.sizing`（`size_entry`、`estimate_fee`）和 `v6lite.risk` 中的相关检查。参数从 `v6lite\examples\paper.toml` 读取。**不要在回测程序里另写一份策略逻辑。** |
| 信号时点 | 交易日 D 的信号只使用 **D 之前**（不含 D）的日线，与 G2 的实测一致：盘中日线不含当天。VIX 用 D−1 的收盘价。<br>V6-Lite 每天扫描两次，但两次用的是同一组日线。日线回测里每天只做一次决策，在报告里说明这一简化。 |
| 入场 | 以 D 日开盘价作为成交价，另加滑点（基准 5 个基点，敏感性测试 0 和 10 个基点）。<br>入场前照搬 V6-Lite 的价格偏离检查：开盘价相对信号价（D−1 收盘）偏离超过 `MAX_PRICE_DRIFT_PCT` 就拒绝入场。<br>ATR 用 D−1 的值，与信号使用的一致。 |
| 定仓与风控 | 资金上限 1 万美元。每笔风险、单笔仓位上限、单笔金额上限，以及最多持仓数、每个板块最多持仓数、每日最多入场次数、日内亏损停止、连续亏损冷却，全部按 V6-Lite 的配置和代码执行。<br>冷却期是分钟级的，日线回测里按“当天剩余时间不再入场”近似处理。 |
| 出场 | 按 V6-Lite 的分段规则：止损为 2.5 倍 ATR；TP1/TP2/TP3 为 3/5/8 倍 ATR，每段卖出三分之一；TP1 之后止损移到保本价。<br>同一根日线内的处理顺序：<br>① 开盘价已经跌破止损：按开盘价成交（跳空）；<br>② 同一天里止损和某个止盈价都被碰到：**一律算先止损**（保守）；<br>③ 只碰到止盈：按止盈价成交，再扣去 V6-Lite 卖出限价的价差。<br>入场当天也要检查出场。止损和止盈的判定要通过 `decide_exit` 完成。 |
| 佣金 | 主结果每次成交都用 `estimate_fee`（保守）。敏感性测试另做两组：① 不计佣金；② 按旧 V6 Paper 的实测水平：每次成交 max(1.00, 0.005×股数)，不乘安全系数。 |
| 统计单位 | 一笔入场到全部出场，算作一笔交易。R = 入场时的计划风险（股数 × 2.5 倍 ATR）。 |
