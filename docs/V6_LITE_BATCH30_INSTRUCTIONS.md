## 1 修复

1. **佣金未回报（先调查）：**
   - 说明 exec `0000dc8f.6bef670d.01.01` 的 commissionReport 为什么一直没有入账。是 TWS 根本没推送，还是推送了但没有匹配上（例如回调先于成交入账、exec_id 匹配失败、重启后没有补订阅），给出证据。
   - 平仓之后，如果仍有佣金未回报：用我们自己发起的 executions 查询补齐（查询返回的结果里带 commissionReport），并遵守现有限速，每 5 分钟最多 1 次，当天最多补查到收盘。补齐后更新账本，日报使用最终值。
   - 收盘时仍未补齐的，日报里写明“佣金未回报 N 笔，按估算 $x 计入”。
2. **平仓卡片和冷却卡片的口径：**
   - 有佣金未回报时，卡片同时给出“已回报净值”和“估算净值”。例如：
     > 毛 3.84；佣金已回报 3.01 + 估算 1.00；估算净值 −0.17（1 笔佣金未回报）
   - 不能只写“net P&L 0.83”。
   - 冷却卡片写出判定依据：分别列出连续亏损的每一笔（持仓 id、净值、是否含估算）。
   - **冷却判定规则不变**：估算净值 < 0 就算亏损。说明 `risk.trade_net` 目前用的估算值和来源。如果是固定常数，改为按该标的近期同类成交的实际佣金来估算，并以配置的最低值兜底。
   - 佣金补齐后，如果最终净值的正负号与估算不同，写审计并发 INFO 说明。是否解除冷却**不自动改变**，只提示。
3. **`TEST_TP_TIMEOUT_RESULT` 降噪：** 只在状态变化时写一行，包括：领取、挂出、撤单请求、撤单确认、恢复确认、迟到成交、作废、P0。等待期间不重复写 status。
4. **日报：**
   - 空窗统计把测试注入单独列出，例如：
     > B（正常）最大 2.063s；B（测试注入）14.256s
   - “空窗 B ≤ 5 秒”的合规判定只看正常止盈。
   - 确认 b29 §5 的 `TEST_TP_TIMEOUT_RESULT` 日报段落存在。如果存在，说明 10/26 的日报为什么没显示；如果漏了，补上。
